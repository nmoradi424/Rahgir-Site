# رهگیر — سایت خدمات جیرا

سایت معرفی خدمات پیاده‌سازی، اتوماسیون و گزارش‌سازی جیرا برای تیم‌های نرم‌افزاری:
قابلیت‌ها، پنج داشبورد نمونه با نمودارهای تعاملی، بسته‌ها و قیمت، و برآوردگر هزینه.

## اجرا روی سیستم

سایت ایستا است و به build نیاز ندارد:

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## ساختار

```
index.html        ساختار صفحه و متن بخش‌های ثابت
css/styles.css    توکن‌های رنگ (روشن/تاریک)، چیدمان و استایل‌ها
js/app.js         بورد زنده، قابلیت‌ها، داشبوردها و نمودارها، قیمت‌ها و برآوردگر، روند کار و پرسش‌ها
```

## جاهایی که باید ویرایش شوند

| چه چیزی | کجا |
|---|---|
| قیمت بسته‌ها (میلیون تومان، بر اساس اندازه تیم) | `js/app.js` → آرایه `plans` و `price` |
| قیمت خدمات اضافه | `js/app.js` → `addonPrice` |
| متن قابلیت‌ها | `js/app.js` → آرایه `caps` |
| داده‌های داشبوردهای نمونه | `js/app.js` → آرایه `dashes` |
| پرسش‌های رایج | `js/app.js` → آرایه `faqs` |
| ایمیل و شماره تماس | `index.html` → بخش `#contact` (کادر `.ph`) |
| رنگ‌ها | `css/styles.css` → متغیرهای `:root` و بلوک‌های تم تاریک |

نمودارها با SVG و بدون کتابخانه رسم می‌شوند و همه داده‌های داشبوردها فرضی‌اند.
